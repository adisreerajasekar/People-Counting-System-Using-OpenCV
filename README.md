# People Counting System Using OpenCV

## Overview
This project focuses on developing a real-time People Counting System using Computer Vision and OpenCV techniques. The system is designed to detect, track, and count the number of people entering or exiting a monitored area through video processing.

The project utilizes Haar Cascade classifiers along with image processing and object detection methods to improve crowd monitoring, surveillance, and smart security applications.

---

## Problem Statement
Manual monitoring of crowd movement in public spaces can be inefficient and error-prone. Automated people counting systems help improve security, occupancy monitoring, and crowd analytics in environments such as malls, offices, transportation hubs, and public events.

This project aims to:
- Detect people in video streams
- Track movement across frames
- Count people automatically
- Improve monitoring efficiency using Computer Vision

---

## Objectives
- Perform real-time video processing
- Detect moving individuals using OpenCV
- Utilize Haar Cascade classifiers for object detection

## Haar Cascade Classifier
Haar Cascade is a machine learning-based object detection approach used to identify objects in images and video streams. In this project, Haar Cascade classifiers are utilized to detect human presence efficiently in video frames.

Advantages of Haar Cascade:
- Fast real-time detection
- Lightweight implementation
- Suitable for surveillance applications
- Works effectively with OpenCV integration
